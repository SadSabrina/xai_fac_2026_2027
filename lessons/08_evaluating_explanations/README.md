# Занятие 08. Можно ли верить объяснению?

Презентация — в чате курса.

## Темы
1. Зачем оценивать: у объяснения модели нет правильного ответа; правдоподобие ≠ верность.
2. Словарь и рамка: свойства Co-12, требования VXAI, пять типов проверки.
3. Без вмешательства (I–II): размер карты, повторяемость, Random Logit, предел таких проверок.
4. Вмешательство во вход (III): Infidelity, Faithfulness Correlation, max-sensitivity, deletion / insertion / AOPC, ROAD; верность цепочки рассуждений.
5. Вмешательство в модель (IV): sanity checks, их изъяны (sMPRT, eMPRT), ROAR.
6. Известный ответ (V) и итог: FunnyBirds, CEBaB; почему метрики спорят; правила чтения.

Примеры — ResNet-34 на четырёх картинках `skimage` (карты: окклюзия, SmoothGrad, Guided Backprop, случайная), RoBERTa для тональности и игрушечная модель «риск поломки станка» — сквозной пример ниже.

---

## 1. Зачем оценивать

Объяснение модели может быть ясным и убедительным — и описывать не то, как модель пришла к ответу. Правильного объяснения у обученной модели нет, если мы его не заложили в данные. **Правдоподобие** — насколько объяснение убедительно для человека; **верность** (faithfulness) — насколько оно отражает, как модель решала (Jacovi и Goldberg, 2020). Люди на глаз меряют правдоподобие.

Аксиомы описывают методы, но не выбирают лучший: IG и DeepLIFT оба полны и дают разные вклады. В обзоре Nauta et al. (2023) из 312 статей 2014–2020 годов, предлагавших новый метод, каждая третья подтверждала его только «анекдотами», каждая пятая проверяла объяснения на людях. Анекдотическое свидетельство (anecdotal evidence, термин авторов) — несколько отдельных убедительных, возможно отобранных примеров, которые проходят проверку на глаз; так проверяется правдоподобие, а не верность. Уровни оценки (Doshi-Velez и Kim, 2017): application-, human- и functionally-grounded; сегодня — третий, формальные метрики.

## 2. Словарь и рамка

**Co-12** (Nauta et al., 2023) — двенадцать свойств в трёх группах:

| Группа | Свойства |
|---|---|
| Содержание | Correctness (верность), Completeness, Consistency, Continuity, Contrastivity, Covariate complexity |
| Презентация | Compactness, Composition, Confidence |
| Пользователь | Context, Coherence, Controllability |

**Свойства нельзя свернуть в один балл.** Они тянут в разные стороны (компактность ↔ полнота), а реализации одной проверки противоречат друг другу.

**Сквозной пример — станок X.** Модель — логистическая регрессия риска поломки за неделю: $z = -0{,}5 + 0{,}5(\text{вибр.} - 4) + 0{,}4(\text{часы} - 3) + 0{,}1(\text{возраст} - 6) + 0{,}2(\text{темп.} - 24)$, $p = \sigma(z)$. Вход — станок X: вибрация 7 мм/с, 500 часов без ТО, 2 года, 25 °C. Выход — $z = 1{,}6$, $p = 0{,}832$: в ремонт. Объяснение — вклады в логит относительно среднего станка $w_i(x_i - \bar x_i)$: 1,5; 0,8; −0,4; 0,2.

**Одна проверка — два победителя.** Метод A считает вклады от среднего станка (1,5; 0,8; −0,4; 0,2; главное — вибрация), метод B — от нулевого (3,5; 2,0; 0,2; 5,0; главное — температура). Проверка удалением: если «удалить» = заменить средним, сильнее всего логит падает без вибрации — прав A; если заменить нулём — без температуры, прав B (хотя 0 °C в данных не бывает). Протокол проверки называют вместе с баллом.

**VXAI** (Dembinsky et al., 2026) — семь измеримых требований (Fidelity, Continuity, Consistency, Parsimony, Plausibility, Coverage, Efficiency) и **пять типов проверки** — рамка занятия:

| Тип | Что делает | Примеры |
|---|---|---|
| I. Только объяснение | модель не нужна | Джини, энтропия |
| II. Наблюдение за моделью | выходы на готовых входах | повторяемость, Random Logit, CoSy |
| III. Вмешательство во вход | портим вход, смотрим на ответ | Infidelity, deletion, ROAD, max-sensitivity |
| IV. Вмешательство в модель | ломаем или переобучаем модель | MPRT, sMPRT, eMPRT, ROAR |
| V. Заранее известный ответ | данные с истиной по построению | FunnyBirds, CEBaB |

Типы I–III говорят о конкретном объяснении вашей модели, IV–V — о методе вообще.

## 3. Без вмешательства (I–II)

**Размер:** $p_i = |a_i|/\sum_j |a_j|$; индекс Джини $G = \frac1n\sum_i (2i - n - 1)\,p_{(i)}$ (0 — поровну), энтропия $H = -\sum p_i\ln p_i$, число признаков выше порога. Станок X: модули вкладов (1,5; 0,8; 0,4; 0,2), сумма 2,9 → доли (0,517; 0,276; 0,138; 0,069); $G = 0{,}371$ из 0,75, $H = 1{,}154$ из $\ln 4$, $e^H = 3{,}17$; выше порога 0,1 — три признака. **Компактность ≠ верность.**

**Предел.** Вход $x = (3; 1; 2)$, baseline 0, вклады (1,2; 0,5; −0,4) точны для $f_1 = 0{,}4z_1 + 0{,}5z_2 - 0{,}2z_3$ и неверны для $f_2 = -f_1$ — метрика уровня I их не различит. Модель $f_3 = f_1 + 0{,}1(z_1 - 3)^2\lVert z - x'\rVert^2\lVert z - x''\rVert^2$ совпадает с $f_1$ на трёх готовых входах $x$, $x' = (1; 0; 1)$, $x'' = (0; 2; -1)$ (1,3; 0,2; 1,2), но замена $z_1$ нулём роняет $f_1$ на 1,2 и поднимает $f_3$ на 25,8 — уровень II не различит.

**Объяснения между собой:** $S = \frac{1}{|P|}\sum \mathrm{sim}(e_a, e_b)$. Повторяемость (сменили зерно — $S$ высокое): KernelSHAP на станке X, три запуска, два главных признака: {вибр., часы}, {вибр., часы}, {вибр., возраст} → Жаккар 1; 1/3; 1/3, $S = 0{,}56$ при случайных 0,39. Random Logit (сменили класс — $S$ низкое): карты для «собаки» (0,8; 0,6; 0,1; 0; 0,3; 0,1) и «кошки» (0,1; 0,2; 0,7; 0,9; 0,1; 0,4) — косинус 0,26, метод видит класс. На картинках: Guided Backprop почти не видит класс (SSIM ≈ 1), случайная карта — 1.

**Ловушки кода Quantus 0.6.0:** нормировка `normalise_by_max` — по всему батчу (балл примера зависит от соседей); RandomLogit считает SSIM по сплющенному вектору; **Consistency** дискретизирует объяснение знаками первых пяти элементов, а после модуля все знаки +1 — метрика от объяснения не зависит.

## 4. Вмешательство во вход (III)

**Infidelity** (Yeh et al., 2019): $\mathbb E_I\big[(I^\top\Phi - (f(x) - f(x - I)))^2\big]$. Возмущение должно соответствовать методу: для градиента × вход на линейной модели нужен декоратор Captum, иначе метрика не 0. На картинках с `normalize=True` все карты ≈ 1, включая случайную.

**Faithfulness Correlation** (Bhatt et al., 2020): корреляция суммы вкладов случайного подмножества и падения прогноза. В Quantus по умолчанию — 224 элемента канал×пиксель (≈ 0,15 % входа), baseline «black» = минимум картинки, логит, без зерна: на картинках все карты около нуля, как случайная.

**Max-sensitivity:** наибольшее изменение объяснения в шаре радиуса $r$. Captum и Quantus делят на норму исходного объяснения. Постоянная карта получает 0 — устойчивость смотрят только вместе с верностью.

**Deletion / insertion / AOPC:** убираем по порядку карты — прогноз должен падать быстро (необходимость), возвращаем — расти (достаточность); $\mathrm{AOPC} = \frac{1}{n+1}\sum_k (D_0 - D_k)$. Станок X («удалить» = заменить средним; порядок карты A — вибрация, часы, температура, возраст): deletion 0,832 → 0,525 → 0,332 → 0,289 → 0,378, Del 0,438, Ins 0,769, AOPC 0,361; обратный порядок — 0,769, 0,438, 0,096; случайная (24 порядка) — 0,613, 0,613, 0,221. На картинках с тёмной заливкой (Quantus RegionPerturbation) при MoRF все карты как случайная: заплатки роняют вероятность сами по себе.

**ROAD** (Rong et al., 2022): заполнение удалённого пикселя средним соседей (1/6 по стороне, 1/12 по диагонали) + шум, чтобы не было видно формы дыры. С ним карты различаются: окклюзия лучшая. `quantus.ROAD` 0.6.0 на RGB падает — считали по авторской импутации.

**Цепочка рассуждений LLM** — тоже объяснение; проверка — то же вмешательство (Turpin et al., 2023; Lanham et al., 2023).

## 5. Вмешательство в модель (IV)

**Sanity checks** (Adebayo et al., 2018): рандомизация весов каскадом сверху вниз и рандомизация меток; сходство — Спирмен, SSIM. Guided Backprop и Guided Grad-CAM проваливают. `quantus.MPRT` рандомизирует каждый модуль по одному (у ResNet-34 — 73 шага), BatchNorm сбрасывает, считает по модулю. Проверка ошибается сама (Binder et al., 2023; Hedström et al., 2023): шум получает хороший балл, каскад сверху вниз оставляет нижние слои — на RoBERTa карта после восьми сломанных слоёв снова сближается с исходной. Поправки — sMPRT и eMPRT; eMPRT при этом ставит Guided Backprop высоко — поправки тоже спорят.

**ROAR** (Hooker et al., 2019): удалить и переобучить; ResNet-50: 76,68 % → 0,5 % без переобучения, 63,53 % с ним. Дорого, и вопрос другой: можно ли выучить класс без этих пикселей.

## 6. Известный ответ и итог

FunnyBirds (птицы из частей, удаление без выхода из распределения) и CEBaB (отзывы, переписанные по одному аспекту). Известный ответ ≠ механизм (занятие 07, Tree-Cycles).

**Метрики спорят:** на одних и тех же картинках порядок четырёх карт по Джини, Random Logit, удалению, ROAD и eMPRT разный.

**Правила чтения метрики:** одна модель и один протокол; случайная карта — нижняя граница; объявлять протокол; сверять формулу статьи и код библиотеки.
