## 1. Линейные модели

**Модель и обучение.**
$$\hat y = \beta_0 + \sum_j \beta_j x_j, \qquad \hat\beta = \arg\min_\beta \sum_i (y_i - \hat y_i)^2 = (X^\top X)^{-1}X^\top y.$$

**Вес** $\beta_j = \partial \hat y / \partial x_j$ — изменение прогноза при +1 к $x_j$ при прочих равных. **Вклад** $\beta_j x_j$ — локальное объяснение одного прогноза; сумма вкладов плюс $\beta_0$ равна прогнозу.

**Масштаб.** Веса сравнимы только в одном масштабе: $\beta_j^{\text{std}} = \beta_j \sigma_j$.

**Функция потерь задаёт, что прогнозируется:** MSE — условное среднее, MAE — медиана, pinball — квантиль.

**Мультиколлинеарность.** Коррелированные признаки делят общий вклад произвольно.
$$\mathrm{VIF}_j = \frac{1}{1 - R_j^2},$$
где $R_j^2$ — качество регрессии $x_j$ на остальные признаки. VIF > 10 — сигнал тревоги.

**Устойчивость веса** — по бутстрапу: $|\mathrm{MEAN}(\beta_j) / \mathrm{STD}(\beta_j)|$. Самый большой вес не обязательно самый надёжный.

**Регуляризация.**
$$\text{Ridge: } \lambda\sum_j \beta_j^2, \qquad \text{Lasso: } \lambda\sum_j |\beta_j|.$$
Ridge сжимает веса, Lasso обнуляет часть из них. Отбор Lasso — не важность: из коррелированных признаков он оставляет один почти случайно.

**Логистическая регрессия.**
$$p = \sigma(z), \quad z = \beta_0 + \sum_j \beta_j x_j, \qquad \log\frac{p}{1-p} = z.$$
Вес — сдвиг лог-шансов; $e^{\beta_j}$ — во сколько раз меняются шансы при +1 к $x_j$. Изменение вероятности зависит от точки на сигмоиде.

**Вероятность ли это.** Log-loss и Brier — proper scoring rules: их оптимум — истинная вероятность. Взвешенный log-loss и focal loss сдвигают прогноз.

**Нюансы и границы.**
- Вес читается только «при прочих равных»; в данных признаки меняются вместе, поэтому вес — утверждение о модели, а не об объекте.
- Веса сравнимы только в одном масштабе.
- $\beta_0$ осмыслен, только если «все признаки равны нулю» что-то значит; после стандартизации это средний объект.
- Сумма вкладов в точности равна прогнозу: локальное объяснение не приближённое.
- Высокий VIF — не ошибка модели, а индикатор: веса группы коррелированных признаков читаются вместе. VIF ловит только линейные связи.
- Большой вес и надёжный вес — разные вещи; если бутстрап-интервал веса пересекает ноль, не определён даже знак. Бутстрап проверяет устойчивость к выборке, а не правильность модели.
- Lasso отбирает признаки, полезные при данном $\lambda$ и данных соседях; веса Lasso смещены к нулю; признаки перед Lasso обязательно стандартизовать.
- В логистической регрессии изменение вероятности зависит от исходной вероятности; вероятностью прогноз можно считать только при proper-лоссе.

**Когда веса можно читать:** признаки осмысленны, масштаб сопоставим, веса устойчивы, нет сильной мультиколлинеарности.

## 2. Каузальность

- **Prediction** — хорошо ли модель предсказывает; **explanation** — как она использовала признаки; **causation** — что изменится в мире при вмешательстве.
$$P(Y \mid X = x) \ne P(Y \mid do(X = x)).$$
- **Потенциальные исходы:** $Y_1$ — исход при воздействии, $Y_0$ — без него. Для каждого объекта наблюдается только один из них.
$$\mathrm{ATE} = E[Y_1 - Y_0], \qquad \mathrm{ATT} = E[Y_1 - Y_0 \mid T = 1].$$
- **Селекционное смещение:**
$$E[Y \mid T=1] - E[Y \mid T=0] = \mathrm{ATT} + \big(E[Y_0 \mid T=1] - E[Y_0 \mid T=0]\big).$$
Рандомизация обнуляет второе слагаемое.
- **Три типа переменных в причинной схеме:**
  - **конфаундер** — общая причина $T$ и $Y$ ($T \leftarrow Z \rightarrow Y$): добавлять в регрессию;
  - **медиатор** — посредник, через который $T$ влияет на $Y$ ($T \rightarrow M \rightarrow Y$): не добавлять, иначе регрессия «съест» часть эффекта;
  - **коллайдер** — общее следствие $T$ и $Y$ ($T \rightarrow C \leftarrow Y$): не добавлять, иначе появится ложная связь.
- **Коэффициент регрессии — причинный эффект,** только если все конфаундеры измерены и добавлены, медиаторов и коллайдеров в модели нет, форма зависимости верна и при каждом значении конфаундеров встречаются и $T=1$, и $T=0$. Если конфаундер не измерен, используют инструментальные переменные или double ML.
- Объяснения модели описывают модель, а не мир.

## 3. GLM, GAM, EBM

- **GLM:** $g(E[Y\mid X]) = \beta_0 + \sum_j \beta_j x_j$. Вес читается в шкале функции связи: для логарифмической связи $e^{\beta_j}$ — во сколько раз меняется среднее.
- **GAM:** $g(E[Y\mid X]) = \beta_0 + \sum_j f_j(x_j)$. Вес становится кривой; прогноз — сумма кривых.
- **EBM:** $g(E[Y\mid X]) = \beta_0 + \sum_j f_j(x_j) + \sum_{(j,k)} f_{jk}(x_j, x_k)$. Кривые обучаются бустингом: каждое дерево строится на остатках по одному признаку и добавляется к его кривой с маленьким шагом; признаки обходятся по кругу, с дополнительными жадными шагами. Пары отбирает алгоритм FAST.
- Локальное объяснение EBM точное: $\beta_0$ плюс вклады равны прогнозу.
- **Нюансы и границы:**
  - кривая читается как вес, зависящий от значения признака; ноль — средний вклад, потому что каждый член центрирован;
  - рваная кривая — переобучение; на краях признака мало данных, и кривая ненадёжна;
  - коррелированные признаки делят вклад: форма кривой зависит от соседей в модели;
  - парный член — поправка к сумме кривых, а не полный эффект пары; пар немного, тройных взаимодействий нет; в областях без данных значения пары ничего не значат;
  - большие вклады с разными знаками могут гасить друг друга;
  - кривая и вклад описывают модель, а не причину.

## 4. Деревья, лес, бустинги

**Дерево.** Кусочно-постоянная функция на прямоугольниках:
$$a(x) = \sum_\ell c_\ell\, \mathbb 1[x \in R_\ell], \qquad \Delta = I(N) - \tfrac{n_L}{n} I(L) - \tfrac{n_R}{n} I(R).$$
Разбиение выбирается жадно по максимуму $\Delta$; $I$ — дисперсия, индекс Джини или энтропия. Объяснение прогноза — путь к листу: ровно те условия, по которым модель приняла решение; его длина равна глубине. Дерево режет только вдоль осей: диагональные границы строит лесенкой, XOR в корне не видит.

**Impurity-важность** — суммарное снижение загрязнённости по узлам признака на обучающих данных. Смещена к непрерывным и многокатегориальным признакам: чем больше возможных порогов, тем выше шанс случайно получить важность, поэтому шумовой признак получает ненулевую важность. Ничего не говорит о новых данных; коррелированные признаки делят её произвольно. Сравнивайте с признаком-пустышкой.

**Лес.** Среднее деревьев на бутстрап-выборках со случайными признаками:
$$\mathrm{Var} = \rho\sigma^2 + \frac{1-\rho}{M}\sigma^2.$$
Зачем гасить дисперсию: ошибка на новых данных = смещение² + дисперсия + шум. У глубокого дерева смещение маленькое, а дисперсия большая — прогноз, путь к листу и важности сильно меняются от выборки к выборке, и объяснению такой модели нельзя доверять. Усреднение снижает дисперсию прогноза и важности, не меняя смещение, но не исправляет смещение самой метрики важности. Плата — одного читаемого дерева больше нет.

**Бустинг.** Деревья по очереди учатся на антиградиенте лосса:
$$F_M(x) = F_0 + \sum_m \nu\, h_m(x).$$

**Встроенные важности.**

| Важность | Вопрос | Может быть < 0 |
|---|---|---|
| impurity (sklearn) | насколько разбиения снизили загрязнённость | нет |
| XGBoost weight | сколько раз признак использован | нет |
| XGBoost gain | насколько разбиения снизили лосс | нет |
| XGBoost cover | сколько объектов задели разбиения (с весом по гессиану) | нет |
| CatBoost PredictionValuesChange | насколько разбиения меняют прогноз | нет |
| CatBoost LossFunctionChange | насколько вырастет лосс без признака | да |

Три важности одной модели могут давать разные рейтинги; признак может часто использоваться в слабых разбиениях (высокий weight при низком gain). «Важность» без указания типа не определена. Все, кроме LossFunctionChange, считаются по обучающим данным.

## 5. Нелинейные модели, объяснимые по построению

- **kNN:** $a(x) = \arg\max_y \sum_{i \in kNN(x)} \mathbb 1[y_i = y]$. Объяснение — соседи, метрика и $k$. В высокой размерности соседи неотличимы от далёких.
- **ProtoPNet:** логит класса $= \sum_j w_{cj}\, g_j(x)$, где $g_j$ — сходство участка снимка с прототипом $p_j$; прототипы заменяются участками реальных обучающих снимков. «Похоже» — в пространстве сети, а не для человека.
- **Mixture of Experts:** $\hat y(x) = \sum_k g_k(x) f_k(x)$, $g = \mathrm{softmax}(W_g x)$. Гейт говорит, кто отвечает, эксперт — почему. Частота выбора эксперта ≠ его важность.
