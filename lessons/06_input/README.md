# Занятие 06. Вход: что во входе важно для ответа?

Презентация — в чате курса. Код всех примеров — [demo_06_input.ipynb](demo_06_input.ipynb): там же теория, псевдокод и нюансы методов.

## Темы
1. Рамка объяснения: единица, процесс, baseline, цель.
2. Что считать признаком: масштаб и цена единицы в разных формах данных.
3. Процесс: вмешательство — зачем оно понадобилось; окклюзия → RISE → LIME; цель — логит или вероятность; текст, ряд, рекомендации.
4. Процесс: градиент — карта чувствительности → SmoothGrad → Integrated Gradients; текст по эмбеддингам.
5. Хрупкие места объяснения через вход.

Данные — лишь форма, в которой задаём вопрос: картинка, текст, ряд, аудио, граф, рекомендации. Примеры — ResNet-34 на картинке из `skimage`, RoBERTa для тональности твитов и игрушечные модели, которые можно посчитать руками.

## 1. Рамка: четыре решения

| Решение | Вопрос | Примеры |
|---|---|---|
| **Единица** | что считаем признаком? | пиксель, суперпиксель, токен, слово, окно ряда, ребро, фильм в истории |
| **Процесс** | что делаем с единицей? | градиент; вмешательство — заменить, удалить, замаскировать |
| **Baseline** | на что заменяем? | ноль, среднее, размытие, [MASK], тишина |
| **Цель** | какое число объясняем? | логит, вероятность, разность логитов, скор, косинус |

Цель частично сопряжена со структурой данных, на которой строится объяснение. Методы занятий 04–05 раскладываются так же: permutation importance — признак, перестановка, маргинальное распределение, R²; SHAP — признак, замена из фона, фон, логит; IG — признак, градиент по пути, baseline, логит.

## 2. Что считать признаком

| Форма | Сырая единица | Единица объяснения |
|---|---|---|
| картинка | пиксель (224×224 = 50 176) | суперпиксель (SLIC, Achanta et al., 2012), окно |
| текст | суб-токен (`unwatchable` → `unw` + `atch` + `able`) | слово |
| ряд | точка (соседние почти одинаковы) | окно |
| аудио | отсчёт | клетка спектрограммы время × частота |
| граф | узел, ребро | ребро, подграф |
| рекомендации | взаимодействие | фильм в истории пользователя |

**Единица задаёт масштаб.** Один метод — убрать единицу и посмотреть на выход:

| Форма | Мелкая единица | Δ цели | Крупная единица | Δ цели |
|---|---|---|---|---|
| картинка (ResNet-34, p tiger cat) | 1 пиксель | 0,006 | 1 суперпиксель · 5 | 0,15 · 0,43 |
| текст (RoBERTa, logit pos − neg) | `unw` · `atch` · `able` по отдельности | −1,30 · −1,42 · −0,47 (Σ −3,19) | слово целиком | −0,40 |
| ряд (детектор: максимум скользящего среднего по 20 точкам, f = 2,92) | 1 точка в пике | 0,07 | окно 140–160 | 0,49 |

Слишком мелкая единица ничего не показывает. Суб-токен — вообще другой вопрос: маска одного куска ломает слово, и сумма вкладов кусков (−3,19) не равна вкладу слова (−0,40). У аддитивных методов (IG, SHAP) вклад слова — сумма вкладов суб-токенов; у вмешательства — нет.

**Уровень ряда** — значение, около которого ряд колеблется; здесь среднее 2,06. «Заменить уровнем» — заменить кусок ряда этим значением.

**Единица задаёт цену** ($d$ — число единиц):

| Метод | Прогонов модели | Картинка | Текст | Ряд |
|---|---|---|---|---|
| окклюзия, leave-one-out | $d$ | 169 окон (35 суперпикселей) | 17 токенов | 12 окон |
| RISE | $N$ масок — задаёте вы | 1000 | — | — |
| LIME | $n$ сэмплов — задаёте вы | 800 | — | — |
| Шепли точно (занятие 05) | $2^d$ | $2^{35} \approx 3{,}4\cdot10^{10}$ | $2^{17}$ | $2^{12}$ |
| градиент | 1 вперёд + 1 назад | 1 | 1 | 1 |
| Integrated Gradients | $m$ шагов | 128 | 600 | — |

## 3. Процесс: вмешательство

**Процесс** — что делаем с единицей. **Вмешательство** меняет *данные*: заменить, удалить, замаскировать единицу и посмотреть на выход. **Градиент** идёт *через модель*: производная выхода по входу. Оба объясняют один вход $x$; разница — где меняем и насколько (конечно или бесконечно мало).

**Зачем понадобилось вмешательство.**
1. **Меняем данные, не модель:** нужен только ответ модели — она может быть чёрным ящиком, сервисом по API, без доступа к весам.
2. **Единица — не координата:** суперпиксель, слово, фильм, ребро — по «наличию» производную не взять.
3. **Модель недифференцируема:** деревья, бустинг, ALS, пайплайны с порогами.
4. **Градиент — про бесконечно малое изменение:** у $\tanh(2x)$ в точке $x = 2$ наклон 0,0027, а $f(2) - f(0) = 1{,}00$. Вопрос «что будет без признака» — про конечное изменение (необходимость, занятие 08).

Общая рамка — объяснение через удаление признаков (Covert, Lundberg, Lee, 2021).

### Окклюзия
**Идея:** важность куска — насколько упадёт цель, если его закрыть (Zeiler & Fergus, 2014).
$$a(R) = f(x) - f\big(x^{R \to b}\big), \qquad a(p) = \text{среднее } a(R) \text{ по окнам } R \ni p.$$
$R$ — окно, $b$ — baseline, $x^{R\to b}$ — вход с окном, заменённым на $b$; $a(p)$ — вклад пикселя.

**Микро-пример.** Картинка 4×4, линейная модель $f = \sum w\cdot x$: веса 1 в правом верхнем углу (яркость 0,9) и 0,5 в левом нижнем (яркость 0,6). $f(x) = 1\cdot0{,}9\cdot4 + 0{,}5\cdot0{,}6\cdot4 = 4{,}8$. Окна 2×2 с шагом 2, baseline 0: закрыть левый верх — $a = 0$; правый верх — $f = 1{,}2$, $a = 3{,}6$; левый низ — $a = 1{,}2$; правый низ — 0. Четыре окна — четыре прогона. Baseline 0,5: вклады 1,6 и 0,2 — отношение 3 : 1 стало 8 : 1, потому что вклад окна равен $w\cdot(x - b)$.

На кошке: окно 32×32, шаг 16, 169 прогонов; ярче всего полосы на лбу.

### Цель: логит или вероятность
$$p_c = \frac{e^{z_c}}{\sum_j e^{z_j}}, \qquad \log p_c = z_c - \mathrm{LSE}(z), \qquad \Delta\log p_c = \Delta z_c - \Delta\mathrm{LSE}, \qquad \frac{\partial p_c}{\partial z_j} = p_c(\delta_{cj} - p_j).$$
Общий сдвиг всех логитов не меняет вероятностей. На кошке:

| Вход | $z$ tiger cat | LSE | $\log p$ | $p$ |
|---|---|---|---|---|
| исходный | 15,55 | 15,99 | −0,44 | 0,64 |
| глаза размыты | 19,35 (+3,80) | 20,16 (+4,17) | −0,81 (−0,37) | 0,45 |
| лоб размыт | 14,18 (−1,37) | 16,13 (+0,14) | −1,95 (−1,51) | 0,14 |

Размытые глаза *повышают* логит tiger cat, но вероятность падает: у Egyptian cat логит вырос ещё сильнее (+5,15). Логит — про класс сам по себе, вероятность — про класс против всех остальных. Карты окклюзии по логиту и по вероятности — Spearman 0,20.

### Зачем RISE: чего не видит окклюзия
Игрушка «ИЛИ»: два глаза A и B, модели хватает любого, $f = \max(A, B)$; C — фон, не используется. Окклюзия: убрать A — $f$ всё ещё 1, вклад 0; так же B и C. «Ничего не важно», хотя без обоих глаз $f = 0$. **Идея RISE** (Petsiuk, Das, Saenko, 2018): закрывать случайную половину много раз; важность — средний ответ, когда кусок открыт:
$$S(\lambda) = \mathbb E_M\big[f(x \odot M) \mid M(\lambda) = 1\big] \approx \frac{1}{Np}\sum_i f(x \odot M_i)\, M_i(\lambda).$$
$M$ — маска 0/1, $p$ — доля открытого, $N$ — число масок.

**Микро-пример** «И»: $f = A\cdot B + 0{,}2\,C$ (кошка — если есть и ухо, и глаз), все 8 масок. $S(A) = (0 + 0{,}2 + 1{,}0 + 1{,}2)/4 = 0{,}6$, $S(B) = 0{,}6$, $S(C) = 0{,}45$. Окклюзия: 1,0 / 1,0 / 0,2. Окклюзия — «без чего», ближе к необходимости; RISE — «с чем, в случайном контексте», ближе к достаточности. На кошке их карты — Spearman 0,01.

### Зачем LIME: чего не даёт RISE
На «ИЛИ» RISE даёт A 1, B 1, фону 0,75 — это просто средний ответ модели: читать можно только относительно среднего; знака и меры доверия нет. **Идея LIME** (Ribeiro, Singh, Guestrin, 2016): подогнать на случайных масках простую линейную модель и сообщить её качество:
$$g(z') = \varphi_0 + \sum_j \varphi_j z'_j, \qquad \varphi = \arg\min \sum_z \pi(z)\,\big(f(z) - g(z')\big)^2.$$
«ИЛИ»: $\varphi_A = \varphi_B = 0{,}5$, фон 0, $\varphi_0 = 0{,}25$, $R^2 = 0{,}67$. «И»: $\varphi_A = \varphi_B = 0{,}5$, $\varphi_C = 0{,}2$, $\varphi_0 = -0{,}25$, $R^2 = 0{,}68$ — суррогат на полной картинке даёт 0,95 вместо 1,2: линейная модель делит взаимодействие пополам.

| Модель «И» | A (ухо) | B (глаз) | C (фон) | Вопрос |
|---|---|---|---|---|
| окклюзия | 1,0 | 1,0 | 0,2 | что пропадёт без куска |
| RISE | 0,6 | 0,6 | 0,45 | скор при случайном контексте |
| LIME | 0,5 | 0,5 | 0,2 | линейная аппроксимация |

Одна модель — три ответа; метод называют рядом с картой. На кошке LIME на 35 суперпикселях: $R^2 = 0{,}63$ на 800 сэмплах.

### Текст: leave-one-out
$a_i = f(x) - f(x_{\setminus i})$, цель — logit(positive) − logit(negative). «The film is not bad.»: $f = 3{,}00$; маска вместо not — $f = -4{,}26$, вклад 7,26; not удалено — $f = -4{,}70$, вклад 7,70; маска вместо bad — вклад 4,76. Маска сохраняет позиции, но такого входа в задаче не было; удаление даёт обычный, но другой текст.

### Ряд, аудио, граф, рекомендации
Ряд — заменить окно (ноль, уровень ряда, интерполяция, шум); аудио — клетку спектрограммы (тишина, шум); граф — удалить ребро; рекомендации — удалить фильм из истории и пересчитать рекомендацию (Ghazimatin et al., 2020).

**Рекомендации, объяснимые по построению.** Соседские модели по фильмам — item-kNN (Sarwar et al., 2001), SLIM (Ning & Karypis, 2011), EASE (Steck, 2019):
$$s_{ui} = \sum_{j \in H_u} B_{ji}, \qquad \text{вклад фильма } j = B_{ji}, \qquad s_{ui} - s_{ui}(H_u \setminus j) = B_{ji}.$$
$B$ выучен на всех пользователях и не зависит от истории, поэтому «потому что вы смотрели X» — точное объяснение. Игрушка: история Матрица (0,30), Терминатор (0,25), Амели (−0,05), скор «Бегущего по лезвию» 0,50; без Матрицы — 0,20, ровно на её вклад. В матричной факторизации вектор пользователя пересчитывается по всей истории — это ДЗ-2.

**Нюансы и границы.**
- Baseline задаёт вопрос «по сравнению с чем»: карты окклюзии с чёрным и размытым baseline — Spearman 0,40, с размытым и средним цветом — 0,95 (Sturmfels, Lundberg, Lee, 2020; Mamalakis, Barnes, Ebert-Uphoff, 2023).
- Цель надо называть: логит и вероятность двигаются даже в разные стороны.
- Нюансы LIME с занятия 05 — ядро, зерно, $R^2$ — остаются.

## 4. Процесс: градиент

**Зачем:** вмешательство платит прогоном за каждый вопрос (кошка: окклюзия 169, RISE 1000, LIME 800). Градиент даёт чувствительность ко всем входам за один обратный проход; плата — нужен доступ к модели, ответ — про малый сдвиг.

### Карта чувствительности
$$s_j = \Big|\frac{\partial f}{\partial x_j}\Big|, \qquad \text{у картинки: } s(h, w) = \max_{c\in\{R,G,B\}}\Big|\frac{\partial f}{\partial x_{c,h,w}}\Big|.$$
Модуль — величина чувствительности без знака; максимум по каналам — одно число на пиксель.

**Микро-пример.** $f = \tanh(2x_1) + x_2$ в точке $(2, 1)$: $f = 1{,}9993$; $\partial f/\partial x_1 = 2(1 - \tanh^2 4) = 0{,}0027$, $\partial f/\partial x_2 = 1$. Вмешательство (заменить на 0) — 1,00 и 1,00. Градиент × вход — 0,0054 и 1: насыщение не лечится.

### Зачем SmoothGrad: градиент сети шумный
Сеть с ReLU кусочно-линейна, и наклон скачет от пикселя к пикселю. **Идея** (Smilkov et al., 2017) — средний наклон в окрестности:
$$\mathrm{SG}_j(x) = \frac1n\sum_{k=1}^n \Big|\frac{\partial f(x + \varepsilon_k)}{\partial x_j}\Big|, \qquad \varepsilon_k \sim \mathcal N(0, \sigma^2).$$
$\sigma$ — радиус окрестности, $n$ — число копий. **Микро-пример:** $\sigma = 1$, 10 копий $x_1 + \varepsilon$: наклоны 0,002; 0,023; 0,044; 0,388 (копия в 0,73) … — среднее 0,046; при $n \to \infty$ — 0,137. На кошке ($\sigma = 0{,}15$ размаха, $n = 25$) карта меняется сильно: Spearman с $|\mathrm{grad}|$ 0,19.

### Зачем Integrated Gradients: насыщение не лечится усреднением
Градиент 0,0027 и SmoothGrad 0,137 — оба про наклон рядом с $x$, а функция выросла на 1,00; сумма их карт ничему не равна. **Идея** — собрать наклон на всём пути от baseline $x'$ (Sundararajan, Taly, Yan, 2017):
$$\mathrm{IG}_j = (x_j - x'_j)\int_0^1 \frac{\partial f\big(x' + \alpha(x - x')\big)}{\partial x_j}\,d\alpha \approx (x_j - x'_j)\cdot\frac1m\sum_k \frac{\partial f\big(x' + \alpha_k(x - x')\big)}{\partial x_j}, \qquad \sum_j \mathrm{IG}_j = f(x) - f(x').$$
**Микро-пример:** baseline $(0, 0)$, 4 шага $\alpha = 0{,}125 \ldots 0{,}875$: наклоны по $x_1$ — 1,573; 0,361; 0,053; 0,007, среднее 0,4985, $\mathrm{IG}_1 = 2 \cdot 0{,}4985 = 0{,}997$; $\mathrm{IG}_2 = 1$. Полнота: 1,997 против 1,9993, остаток 0,0019 (на 50 шагах — 0). На кошке: чёрный baseline — $\Sigma\,\mathrm{IG} = 16{,}01$ при $\Delta f = 15{,}97$; размытый — 12,73 при 12,77.

### Текст: IG по эмбеддингам
У токена производной нет — берут градиент по эмбеддингу; вклад токена — сумма по координатам: $\mathrm{IG}_t = \sum_d \mathrm{IG}_{t,d}$. **Микро-пример:** два токена, эмбеддинг из трёх чисел, $f = w\cdot\sum_t e_t$, $w = (1, 2, -1)$, baseline — эмбеддинг маски $(0;\,0{,}1;\,0)$. Для линейной $f$: $\mathrm{IG}_{t,d} = (e_{t,d} - e'_{t,d})\,w_d$. Токен 1: 0,4; −0,6; −0,7 → −0,9. Токен 2: 0,1; 1,6; 0,3 → 2,0. Сумма 1,1 = $f(x) - f(x') = 1{,}5 - 0{,}4$. На RoBERTa: 600 шагов, остаток 0,05; Spearman(IG, LOO) 0,88.

| Форма | Градиент | Если нет — вмешательство |
|---|---|---|
| картинка, ряд, аудио | есть | окклюзия, RISE, замена окна или клетки |
| текст | по эмбеддингам | маска, удаление слова |
| граф | по весам рёбер, если сделать их непрерывными | удаление ребра |
| рекомендации (ALS), деревья | нет | удаление из истории; TreeSHAP (занятие 05) |

## 5. Хрупкие места

- **Замена уводит вход из распределения.** Сетка чёрных квадратов превращает кошку в дуршлаг (strainer 0,92); те же квадраты, размытые, оставляют tiger cat (0,31). Метрики, которые это учитывают (ROAR, Hooker et al., 2019), — занятие 08.
- **Отрицание и композиция.** Вклад `not` −8,96 в «not good» и +7,26 в «not bad»; `bad` в «not bad» получает +4,76. Одно число на токен описывает вклад в контексте, а не правило «not инвертирует».
- **Единица режет событие.** Сдвиг сетки окон разрезает событие между окнами; помогают несколько сеток и перекрывающиеся окна.
- **Насыщение, шум, сдвиг входа.** Постоянный сдвиг входа, который модель компенсирует, меняет атрибуции многих методов (Kindermans et al., 2017).
