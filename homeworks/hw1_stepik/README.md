# ДЗ-1. Интерпретируемые модели и post-hoc на таблицах

**Курс:** «Интерпретируемые модели AI». Решать можно на любой из двух платформ — блоки одинаковые и бесплатные:

- **сайт школы:** [ai-interpretability.school](https://ai-interpretability.school);
- **Stepik:** [stepik.org/course/228094](https://stepik.org/course/228094).

## Как перейти на сайт

1. Зарегистрируйтесь на [ai-interpretability.school](https://ai-interpretability.school) и запомните почту, с которой регистрировались, — по ней будут искать ваши баллы.
2. Проходите те же блоки, что на Stepik. Блоки по SHAP и LIME появятся на сайте в течение ближайшей недели.

Баг-репорты по сайту — через форму на сайте.

## Что входит в ДЗ-1

Оценку за ДЗ-1 дают практические блоки курса — блоки вида «…: практика». Их четыре:

| Практический блок | Модуль | К занятию |
|---|---|---|
| Линейные модели: веса, регуляризация и прогнозы | Линейные интерпретируемые модели | 03 |
| Лес | Нелинейные интерпретируемые модели | 03 |
| Основы семейства SHAP-методов: практика | Методы объяснений | 05 |
| LIME: практика | Методы объяснений | 05 |

Оценка за ДЗ-1 = доля баллов за эти четыре блока × 10.
